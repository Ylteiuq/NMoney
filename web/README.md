# 账本网页

页面使用原生 HTML、CSS 和 JavaScript。项目根目录运行 `python3 app.py --open`，即可通过本地服务查看。

| 文件 | 作用 |
| --- | --- |
| [index.html](index.html) | 概览、交易明细、相似支出、导入账单四个视图，以及编辑用途和关联回款的对话框。 |
| [style.css](style.css) | 颜色、排版、表格、图表和小屏布局。 |
| [app.js](app.js) | 读取账本数据，处理筛选、排序、分页、图表和操作请求。 |
| [favicon.svg](favicon.svg) | 浏览器标签页图标。 |

概览将实际支付与退款、群收款抵扣并列展示。日常分类环图和可点击的分类列表共用后端的日常金额，点击后查看该分类的日常明细，悬停或用键盘聚焦分类可在圆环中央预览金额。最近交易显示当前筛选范围内最新五笔。桌面明细将商户、平台与时间、金额分列，小屏将平台和时间收进交易摘要。交易明细按时间排序时按日分组，按金额排序时使用全范围排名。展开流水可核对原额、实付和订单号，再编辑用途或日常归属。

**从分类图追到一条流水。** 从概览点分类，地址中的 `#` 片段记录选中的分类和筛选条件。`applyRoute` 恢复视图，`renderDetails` 对服务返回的 `rows` 应用分类、关键词和排序，每页展示 40 笔。原金额和个人实付都以分传输，在展示时转换为元。

**从页面操作追到数据库。** 普通写入经 `post` 发送 JSON，并带上服务要求的请求头。导入经 `importFiles` 直接传文件字节。日常归属使用后端接口保存；`syncChoices` 按平台和订单号迁移旧版浏览器暂存的选择。

请求和响应字段见[接口说明](../nmoney/controllers/README.md)。添加新的静态资源 URL 时，在后端的[路由表](../nmoney/http/router.py) 注册文件和类型。

概览的月度额度按整月、全部平台的收入减去已计入的日常开支计算。导入支持多选和跨目录追加，队列逐文件展示结果。相似支出默认只展示日常归属待确认的流水，可以取消勾选查看全部。

相似支出页读取后端返回的流水 ID 分组，仅负责展开、过滤与批量复核。月度额度管理可将一笔到账流水关联到原借款，并核对剩余本金或确认结清。

导航指示、明细展开和导入反馈的动画由 CSS 控制，跟随系统的减少动态效果设置。
